# LUCID

## Overview

LUCID is an iOS application focused on digital eye health.  
The app is designed to reduce digital eye strain and promote healthier visual habits through structured eye tests and guided exercises.

---

## What the Project Is About

LUCID provides:

- Interactive vision tests
- Guided blink training
- Eye exercise modules
- Structured user flow with login and profile management

The project serves as a foundation for a scalable eye-care platform that can later integrate advanced monitoring and analytics features.
